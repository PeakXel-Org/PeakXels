**Astrologika** - a 2D offline single-player entertainment-first puzzle-adventure mystery game integrated with educational concepts designed to provide supplementary learning support for Grade-12 General Physics 1.
The game combines astral-steampunk elements, narrative-driven exploration, puzzles, and interactive challenges to introduce and reinforce physics concepts through gameplay.

**Project Name:** Astrologika
**Genre:** Puzzle-Adventure
**Theme:** Astral-steampunk
**Game Engine:** Godot
**Platform:** Mobile
**Game Mode:** Offline, Single-player
**Target Audience:** Grade 12 Students
